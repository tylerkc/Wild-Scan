# 🐾 WildScan Demo

WildScan is an AI-powered wildlife image classifier and detector.  
It uses **MegaDetector v5** to locate animals in an image, then classifies the cropped regions with our custom **ScratchResNet** model.

---

## 📦 Requirements

- Python **3.10**
- NVIDIA GPU (CUDA optional but recommended for speed)
- Installed dependencies from `requirements.txt`

---

## 1️⃣ Installation

### Clone the repository
```bash
git clone https://github.com/<your-username>/wildscan.git
cd wildscan
```

### Create & activate a conda environment
```bash
conda create -n wildscan python=3.10 -y
conda activate wildscan
```

### Install dependencies
```bash
pip install -r requirements.txt
```

---

## 2️⃣ Model Files

This demo requires **three files**:

| File | Description | Availability |
|------|-------------|--------------|
| `classes.json` | Class index → species mapping | ✅ Included in repo (`demo/classes.json`) |
| `wildscan_best_scratch_model.pt` | Trained ScratchResNet classifier | ❌ Generated by running `ScratchResNet_Model.ipynb` |
| `md_v5a.0.0.pt` | MegaDetector v5 YOLOv5 weights | ❌ Download from link below |

📌 **How to get them:**
1. **`wildscan_best_scratch_model_csv.pt`** → Run the `ScratchResNet_Model.ipynb` notebook in this repository. It will generate and save the file into the `demo/` folder.  
2. **`md_v5a.0.0.pt`** → Download from:  
   ```
   https://github.com/agentmorris/MegaDetector/releases/download/v5.0/md_v5a.0.0.pt
   ```
   Place the file in the `demo/` folder.

---

## 3️⃣ Updating File Paths

In `wildscan_demo.py`, update the **File Paths & Config** section at the top if needed:

```python
WEIGHTS = r"demo/wildscan_best_scratch_model_csv.pt"
CLASSES = r"demo/classes.json"
DETECTOR_WEIGHTS = r"demo/md_v5a.0.0.pt"
```

💡 On Windows, remember to either:
- Use raw strings: `r"C:\path\to\file.pt"`
- Or escape backslashes: `"C:\\path\\to\\file.pt"`

---

## 4️⃣ Run the Demo

From the project root, launch the Gradio app:

```bash
python wildscan_demo.py
```

This will:
1. Load MegaDetector v5 for bounding box detection.
2. Load ScratchResNet for classification.
3. Start a **Gradio** interface in your browser.

---

## 5️⃣ Using the Interface

- **Upload** an image containing wildlife.
- The system will:
  1. Detect animals in the image.
  2. Draw bounding boxes.
  3. Display **top-5 predicted species** with confidence scores.
- You can **flag** misclassifications or low-confidence predictions for review.

---

## 🛠 Troubleshooting

- **FileNotFoundError** → Check your `WEIGHTS`, `CLASSES`, and `DETECTOR_WEIGHTS` paths.
- **CUDA not available** → Runs on CPU (slower). Install GPU drivers + CUDA for speed.
- **Gradio not launching** → Check that `gradio` is installed and no other process is using the same port.
